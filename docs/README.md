# Documentação

Esta pasta contém a documentação técnica do Controle de Presença.

O objetivo é permitir que um desenvolvedor novo consiga entender o projeto sem precisar estudar todo o código primeiro.

## Por onde começar?

Se você acabou de chegar no projeto, recomendamos esta ordem:

1. [Visão geral](01-visao-geral.md)
2. [Arquitetura](02-arquitetura.md)
3. [Domínio e regras](03-dominio-e-regras.md)
4. [Fluxo de presença](04-fluxo-de-presenca.md)

Depois, consulte os documentos específicos conforme necessário.
